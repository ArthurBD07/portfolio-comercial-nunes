## 📌 Sobre o projeto

Este portfólio apresenta projetos voltados a diferentes segmentos, demonstrando como o desenvolvimento web pode contribuir para a presença digital de profissionais e negócios.

Entre os trabalhos apresentados estão conceitos de sites para hamburgueria, nutricionista e personal trainer.

**Principais características:**
- Design moderno e responsivo.
- Interfaces adaptadas para dispositivos móveis.
- Navegação intuitiva e experiência do usuário.
- Componentização e organização do código.
- Atenção ao desempenho e à identidade visual.
